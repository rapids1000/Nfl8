# NFL Engine 8

Open it at https://rapids1000.github.io/Nfl8/

The `relay` folder is filled by the **Stats relay** GitHub Action every 4 hours. It turns free nflverse data
(play-by-play EPA, injury reports, snap counts, Next Gen separation, FTN charting) into one small file per season
that the engine reads. To refresh it right away: Actions → Stats relay → Run workflow.
